# MISTNET 2.5.1 — финальная полировка

## Hero
- Убрана текстовая метка `Ctrl K` из шапки, вместо неё добавлена компактная кнопка поиска с иконкой; сочетание Ctrl+K сохранено.
- Добавлена статическая SVG-визуализация сетевой схемы между левым статус-блоком и правой панелью серверов — без новой WebGL-сцены.
- Скорректированы вертикальные отступы первого экрана, чтобы контент не заходил под фиксированную навигацию при обычной загрузке.

## Ping / API
- До настройки API выводятся изменяющиеся DEMO-значения в диапазоне 42–94 мс.
- Демонстрационные цифры подписаны и не обозначают фактическую задержку или доступность серверов.
- Когда API настроен, отображаются только его данные. При ошибке upstream демо не маскирует проблему.
- Демо-маркировка скрывается после получения реального ответа API.

## Сохранено из 2.5
- Cabinet-first CTA, общая страница Quick Purchase, Telegram как альтернатива.
- SEO metadata, canonical, Open Graph, Twitter, robots, sitemap и JSON-LD.
- Структура секций и исходная айдентика MISTNET.
- Пониженная нагрузка WebGL и fallback без CDN / при reduced motion / Save-Data.
- Отзывы и неподтверждённые цифры не добавлялись.
