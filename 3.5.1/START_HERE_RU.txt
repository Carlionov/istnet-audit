MISTNET 2.5.4 — ОБНОВЛЕНИЕ ДИЗАЙНА И ВЫРАВНИВАНИЯ

СТЕК
Next.js + React + TypeScript + CSS. Tailwind не используется: проект продолжает использовать собственные CSS-файлы.

УСТАНОВКА
1. Сделайте резервную копию текущего проекта.
2. Распакуйте архив в новую папку или поверх существующего проекта.
3. Сохраните собственный .env.local (его нет в архиве).
4. В корне проекта выполните:

   npm ci
   npm run qa:release

5. Для локальной production-проверки:

   npm run start
