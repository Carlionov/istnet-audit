# MISTNET — этап 3.3.3: доступность и клавиатурная навигация

## Основание этапа

В предыдущей документации отдельное название следующего этапа не задано. Этап 3.3.3 выбран как следующий логичный шаг после унификации CSS и SVG: закрыть найденные проблемы доступности в FAQ, мобильном меню и кнопке командной палитры.

## Что изменено

### 1. Свёрнутые ответы FAQ

В `src/app/mistnet-v2.css` добавлено:

- закрытый `.faq-answer` получает `visibility: hidden`;
- у `.faq-item.active .faq-answer` устанавливается `visibility: visible`.

Это сохраняет существующие анимацию высоты и DOM-структуру, но исключает ссылки внутри закрытого ответа из клавиатурной навигации и дерева доступности. Runtime продолжает управлять `.active` и `aria-expanded` как прежде.

### 2. Возврат фокуса из мобильного меню

Создан `src/components/MobileMenuA11y.tsx` — небольшой клиентский помощник с `useEffect`, который:

- возвращает фокус на `#burger`, если открытое меню закрывается клавишей Escape;
- возвращает фокус на `#burger` при выборе ссылки меню;
- удаляет собственные обработчики при размонтировании.

Компонент возвращает `null` и подключён на странице через `src/app/page.tsx`. `Header.tsx` остаётся Server Component; обработчики React в него не добавлялись. Открытие/закрытие меню, классы, `aria-hidden` и `aria-expanded` остаются под управлением существующего `public/mistnet-runtime.js`.

### 3. Командная палитра

Кнопке `#palOpen` в `src/components/Header.tsx` добавлены:

- `aria-controls="pal"`;
- `aria-haspopup="dialog"`;
- `aria-keyshortcuts="Control+K Meta+K"`, что отражает поддержку Ctrl+K и Cmd+K в runtime.

Существующие ID сохранены.

## Что не менялось

- `public/mistnet-runtime.js` — побайтно не изменён.
- ID `burger`, `mnav`, `palOpen`, `pal`, `palIn`, `palList`, `palClose` не переименовывались.
- Существующие классы и data-атрибуты runtime сохранены.
- Геометрия Hero, сетки, иллюстрации, дизайн-токены и иконки не менялись.

- Статические проверки: связь `#palOpen` → `#pal`, отсутствие React event props в серверном `Header`, подключение клиентского помощника, условия focus restore, состояния видимости FAQ — PASS.
- SHA-256 `public/mistnet-runtime.js` совпадает с 3.3.2.2: `29f9d7a2d38a1556daa01af9b1c3fafaddbdb54c992f241d704def9842ffbe90`.

## Ограничения проверки

Полные `npm run lint`, `npm run typecheck` и `npm run build` не объявляются пройденными: зависимости проекта в рабочей среде не установлены. Headless Chromium зависает при запуске, поэтому интерактивный браузерный тест и визуальная проверка реальной страницы не подтверждены. Синтаксическая транспиляция не заменяет полный TypeScript typecheck.

## Установка

Этап поставляется как полная копия проекта. При ручном переносе замените:

- `src/app/mistnet-v2.css`
- `src/app/page.tsx`
- `src/components/Header.tsx`

И добавьте:

- `src/components/MobileMenuA11y.tsx`

Остальные файлы остаются из этапа 3.3.2.2.
