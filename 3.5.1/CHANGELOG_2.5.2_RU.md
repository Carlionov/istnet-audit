# MISTNET 2.5.2 — финальный релиз перед публикацией

## Последняя полировка Hero
- Убрана текстовая надпись Ctrl K из навигации; быстрый поиск доступен через иконку и сочетание Ctrl+K.
- Центральная пустая зона Hero заполнена спокойной SVG-схемой четырёх локаций. На узких экранах схема скрывается, чтобы не перекрывать колонки и мобильный контент.
- Скорректирована вертикальная позиция схемы под фактическую высоту правой колонки с роботом и панелью конфигураций.
- Увеличен верхний отступ первого экрана относительно фиксированной шапки.

## Demo ping / мониторинг
- При отсутствии настроенного API интерфейс показывает демонстрационные значения 42–94 мс, которые плавно меняются.
- Значения маркируются DEMO и сопровождаются предупреждением: это не реальные измерения и не показатель доступности узлов.
- Настроенный мониторинг заменяет демонстрационные значения фактическими данными. При ошибке API демонстрация не маскирует ошибку.

## Производительность и стабильность
- Базовые меню, FAQ, переходы и CTA инициализируются до завершения загрузки необязательных библиотек анимации.
- Three.js/GSAP остаются необязательными progressive enhancements; для слабых устройств, Save-Data и reduced motion есть облегчённые сценарии.
- SVG-схема не создаёт дополнительную WebGL-сцену.

## Сохранено
- Оригинальная визуальная айдентика MISTNET и маскот.
- Cabinet-first путь: личный кабинет и подтверждённая общая Quick Purchase-страница.
- SEO metadata, canonical, Open Graph, Twitter cards, robots, sitemap и JSON-LD.
- START/TITAN, четыре локации и конфигурации проекта.
- Отзывы и неподтверждённые технические обещания не добавлялись.
