# MISTNET 2.4 — интеграция личного кабинета

## Главный пользовательский путь
- Основной CTA, бесплатный тест и плавающая кнопка открывают `https://lk.mistnet.ru`.
- START и TITAN ведут на единый Quick Purchase: `https://lk.mistnet.ru/buy/mistnet`.
- На Quick Purchase пользователь сам выбирает тариф, период и платёжный метод. В кнопках сайта используется нейтральный текст «Перейти к оформлению», поскольку URL не подтверждает автоматический выбор тарифа.
- Telegram-бот сохранён как дополнительный способ; поддержка в Telegram остаётся доступной из футера.

## Обновлённые разделы
- Header и мобильное меню.
- Hero и главное предложение.
- Карточки START / TITAN.
- «Как подключиться» — сценарий без обязательного Telegram.
- FAQ: вход без Telegram, пробный период, покупка, гостевой Quick Purchase и email.
- Final CTA, Footer, плавающая кнопка личного кабинета.
- Command Palette (`Ctrl + K`).
- SEO description и документация проекта.

## Централизация ссылок
Ключевые ссылки собраны в `src/lib/links.ts`.

## Важные замечания
- Не добавляйте `?plan=...` или иные неподтверждённые параметры выбора тарифа. В документации Quick Purchase описан `?contact=...` для предзаполнения контакта.
- Для отдельного перехода сразу на START или TITAN можно создать в админке Cabinet отдельные Quick Purchase лендинги, каждый с одним разрешённым тарифом, а затем заменить URL в `src/lib/links.ts`.
- Покупка по Email зависит от настроенного SMTP в Cabinet/боте.
