# Шаг 3.2 — Footer и SVG-иконки

## Изменения

- Footer вынесен в `src/components/footer/Footer.tsx`.
- Брендовая колонка, колонки навигации и нижняя строка выделены в отдельные компоненты.
- Ссылки вынесены в типизированные данные `footer.data.ts`.
- Компонент Footer использует исходные CSS-классы; глобальные CSS-файлы не изменялись.
- SVG-рендерер особенностей сайта выделен в `src/components/icons/FeatureIcon.tsx` и используется TrustBar.
- Поведение открытия ссылок сохранено: якоря, кабинет и Quick Purchase открываются в текущей вкладке; Telegram support и bot — в новой вкладке.

## DOM-контракты

Runtime `public/mistnet-runtime.js` не содержит селекторов Footer. Сохранены все классы Footer:

- `.footer`
- `.footer-inner`
- `.footer-brand`
- `.logo`
- `.footer-col`
- `.footer-bottom`

Идентификаторов и `data-*` атрибутов в исходном Footer не было. Сохранён `data-track="quick_purchase"` на ссылке покупки.

## Текстовые символы и иконки

В исходном `Footer.tsx` не было декоративных стрелок, галочек, крестиков, звёзд, ромбов или emoji. Символ `©` оставлен как юридическое обозначение copyright, а не декоративная иконка.

Соседняя полоса функций (`TrustBar`) уже содержала SVG, а не текстовые звёздочки. Её SVG-код извлечён в общий типизированный компонент. Соответствия:

- WireGuard → `shield`
- VLESS / XHTTP → `network`
- Hysteria → `activity`
- 4 локации → `globe`
- Вход без Telegram → `user`
- Тест 3 дня → `gift`

Все SVG используют `stroke="currentColor"`, размер по умолчанию 18 px и толщину штриха 1.7.

## CSS

`globals.css` и `mistnet-v2.css` не изменялись. Сетка, gap, hover/focus иконок и ссылок остаются задачей этапа 3.3.

## Проверки

Проверены структура файлов, импорты, неизменность ссылок, сохранение классов, отсутствие inline-стилей в новых компонентах и неизменность `public/mistnet-runtime.js`.

Полные `npm run lint`, `npm run typecheck`, `npm run build` следует запустить в локальном окружении с установленными зависимостями.
